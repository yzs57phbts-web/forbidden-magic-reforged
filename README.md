# Forbidden Magic: Reforged

Неофициальный перенос Forbidden Magic 0.575 для Thaumcraft 4 на Minecraft 1.21.1 / NeoForge, с восстановленным Таумономиконом и русским переводом.

Текущий выпуск: **1.4.1**.

## Для запуска

Нужны **Minecraft 1.21.1**, **Java 21** и **NeoForge 21.1**; общая сборка проверена на **21.1.264**.

- [Наш Thaumcraft 4: Reforged 1.1-bbtt.30-filter.1](https://github.com/yzs57phbts-web/thaumcraft-4-reforged-dop/releases/tag/1.21.1-bbtt.30-filter.1).
- [Curios API 9.5.1](https://www.curseforge.com/minecraft/mc-mods/curios/files/6529130) и [TerraBlender 4.1.0.1+ для NeoForge](https://www.curseforge.com/minecraft/mc-mods/terrablender-neoforge/files/6054947) — зависимости ядра T4. Для совместных проверок использовался TerraBlender 4.1.0.8.
- Botania Revived и Blood Magic включают соответствующие разделы. Twilight Forest необязателен. Witchery не является обязательной зависимостью.

Скачайте JAR из [релиза 1.4.1](https://github.com/yzs57phbts-web/forbidden-magic-reforged/releases/tag/1.21.1-v1.4.1) и положите в `mods` вместе с зависимостями. В папке должна быть одна версия каждого мода.

## Добавили

Перенесённое содержимое, доступное в этой версии:

- Семь дополнительных аспектов, осколки грехов и связанные исследования.
- Клетка гнева, кристаллы душ и передача эссенции через трубы Thaumcraft.
- Морфические инструменты, секира собирателя черепов, рапира, вилка и специальные чары.
- Набалдашник перемещения, заражённая древесина, растения и магические материалы.
- Необязательные интеграции Botania и Blood Magic; выбранные обычные существа Twilight Forest для клетки.

## Пофиксили

- Восстановлены исходные страницы, связи исследований и оригинальная русская проза.
- Исправлены слой и значок набалдашника, модели растений и парящих цветов.
- В 1.4.1 рапира получила тонкую объёмную модель с крестовиной и короткой рукоятью; исходная иконка и характеристики сохранены.
- У парящего цветка устранены двойная отрисовка островка и случайное смещение.
- Исправлены геометрия вилки и отдельное изображение вилки в инвентаре.
- Устранены проверенные пропуски механик оригинала в инструментах, очистителе, ритуалах и специальных эффектах.

## Адаптировали

- Секира использует современный профиль топора с сохранением специальных эффектов FM.
- Клетка проверяет загруженность чанков, границы мира, коллизии и подходящую среду для существа.
- Входы рецептов и некоторые материалы приспособлены к современным предметам и тегам.

## Изменили

- Клетка использует явный список разрешённых видов Minecraft, Thaumcraft и Twilight Forest с исключением боссов и служебных существ.
- Поглощение поддерживает дополнительные современные породы камня; заражение саженцев — современные ванильные виды.
- Сумеречная роза выдаёт ванильный чёрный краситель; старый пигмент сохранён для совместимости.
- Вилка использует заданные параметры железного топора: 9 урона, 0,9 скорости атаки и 250 прочности, сохраняя эффекты FM.

## Совместимость и проверки

Выпуск рассчитан на API нашей доработанной версии T4. Совместимость с чистым авторским T4 автоматически не предполагается.

Опубликованный JAR совпадает по SHA256 с выбранным установленным выпуском. Эта комбинация участвовала в проверке полной сборки: загрузка, настоящий Creative-мир, вкладка T4, прокрутка предметов и повтор после перезагрузки ресурсов. Это не означает полного прохождения всех механик каждого аддона. Подробности текущего выпуска и ограничения сохранены в исходниках/уведомлениях проекта; старые отчёты относятся к своим версиям.

## Сборка из исходников

Положите совместимые JAR нашего T4, Botania Revived, Blood Magic и Curios в `libs/`; эти зависимости не входят в исходники и выпускной JAR. Для T4/Botania также доступны параметры `-PtcJar=/путь/к/T4.jar` и `-PbotaniaJar=/путь/к/Botania.jar`. Регенерация из оригинала требует отдельной локальной копии эталона 0.575.

```sh
./gradlew build
```

Нужен JDK 21. Машинные пути разработчика, эталонные сторонние JAR, игровые миры и конфиги профиля в репозиторий не включены. Скомпилированный выпуск находится в GitHub Releases; `SHA256SUMS.txt` позволяет проверить скачивание.
